Advanced rules

Let repeat work
name itself.

A rule can be as precise as one URL or as broad as an entire domain. Everything stays local, visible and under your control.

01

Exact URL

Give one fixed page a dependable name. Perfect for a dashboard, a document or the one link you return to all day.

https://example.com/projects/today
02

URL pattern

Use {1} placeholders or regular-expression capture groups for URLs that change while their meaning stays the same.

https://app.example.com/{1}/tasks/{2}
03

Domain

Apply a clear, shared name to every page under one hostname. Ideal for admin tools and environments.

staging.example.com

Predictable by design

One page. One clear winner.

When multiple rules match, Tab Rename resolves them in a fixed order. A name created directly on the page always wins.

  1. 1Page or tab-session name
  2. 2Exact URL
  3. 3URL pattern
  4. 4Domain
