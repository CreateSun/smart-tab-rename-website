# Tab Rename landing page

A framework-free, bilingual static site designed for Cloudflare Pages.

## Local preview

```bash
npm install
npm run dev
```

## Deploy to Cloudflare Pages

1. Log in with `npx wrangler login`.
2. Run `npm run deploy` from this directory, or connect this folder to a Cloudflare Pages project.
3. For Git-based Pages deployment, set the root directory to `landingpage`, use no build command, and set the output directory to `.`.

The Chrome Web Store buttons point to the extension's submitted store item. They become installable once the item is published by Chrome Web Store review.
